# ElexStore-sales-system
This is a group project for school assignment. It runs locally only. I mainly responsible to build the user profile and order management modules, implementing profile updates, secure password changes, photo uploads, order cancellation, and admin order tracking using PHP, HTML, CSS, and MySQL

The password reset is through the members' registered email. Admin and Member  First, administrators manage the system through a control center where they can create, update, or delete staff accounts and manually toggle account statuses between active and blocked.  Second, the admin handles all inventory tasks by manually adding product stock, managing product details through CRUD operations, and updating member order statuses. Third, members utilize a persistent shopping cart that saves items across sessions and allows for checkouts that automatically trigger a decrease in product stock levels. Finally, members can independently view their order history, reset forgotten passwords via email, and update personal profile details including their contact information and photo.
